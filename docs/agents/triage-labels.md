# Triage labels

Local-markdown tracker uses these `Status:` role strings (equal to the label name):

| Role | Status string |
|------|---------------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

When work is finished on a ticket, append an `## Answer` / completion note and set `Status: resolved` (wayfinder) or leave `ready-for-agent` checked off via acceptance criteria.
